# FX 全真 · 外汇教学模拟盘

面向手机端的**外汇模拟交易 + 新手教学**单页应用。纯前端，无后端、无依赖、无 CDN，打开即用。

## 功能

**行情**
- 5 个品种：EUR/USD、GBP/USD、USD/JPY、XAU/USD、BTC/USD
- 随机游走 + 均值回归的实时报价，涨跌以「点」计
- 按外汇 / 贵金属 / 加密分类筛选

**交易**
- Canvas 手绘 K 线：1m / 5m / 15m / 1H，MA5 / MA20，RSI(14) 副图，现价线
- 市价单、限价单，0.01–1 手，实时估算保证金与每点价值
- 止损 / 止盈方向校验；未设止损时的风险提示

**持仓**
- 净值、已用保证金、可用、保证金比例条
- 实时浮盈浮亏、点数；改止损止盈、平半仓、全平
- 挂单自动撮合、历史记录（标注止损 / 止盈 / 强平 / 手动）
- 保证金比例 50% 强平，带负余额归零保护

**教学**
- 五关任务链，按真实操作判定通关
- 杠杆实验室、爆仓实验室
- 随堂测验（8 题带解析）、模拟考试（15 题限时 10 分钟，80 分及格）
- 12 个名词卡、复盘统计（胜率 / 盈亏比 / 无止损次数）
- 结业证书；进度保存在 localStorage

## 运行

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080
```

或直接用浏览器打开 `index.html`。

## 结构

```
index.html   页面骨架
style.css    全部样式（移动端优先）
data.js      品种参数、课程、题库、名词表
engine.js    行情引擎 + 账户与撮合
chart.js     Canvas K 线渲染
app.js       界面交互与主循环
```

## 说明

全部为模拟环境：报价由本地随机过程生成，不接入任何真实行情源。仅用于学习交易概念，不构成任何投资建议。
